## Motivação (palavras do usuário)

Treinar quem tem vontade de programar a já pensar na lógica de como cada função de um
software funciona — a parte mais importante é saber pensar em como resolver o problema e
qual algoritmo usar; a linguagem de programação é só a ferramenta.

## Evidência de apoio

Relatório PROEX (aplicação de 19/06/2026, 33 alunos): professores relataram que os alunos
não tinham domínio de desenvolvimento web para os níveis normal/difícil.
